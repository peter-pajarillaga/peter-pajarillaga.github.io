# Humanoid VEXA Webinar Registration Demo

Open `index.html` locally to preview. Upload `index.html` and the `assets/` folder to the root of a GitHub repository to publish using GitHub Pages.

This is a static visual demo. The registration form intentionally does not transmit or save information. Replace the demo form with the approved GHL form and connect the webinar redirect before launch. Confirm webinar claims and compliance text with the client.
